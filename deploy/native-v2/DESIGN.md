# ALN 内网数据平台原生部署方案

## 目标与数据分工

服务器为共享数据的权威存储：保留原始 ZIP/SNP、文件目录、指标数据库、对照表和任务状态。
个人电脑保留指标数据库副本及自己上传的性能表格。服务器上的原始 SNP 不会自动下载到电脑；点击曲线时由服务器读取原始数据并返回曲线数组，只有主动下载才保存原始文件。同事也可以在电脑上传 SNP/ZIP：网页端直接上传服务器；软件端先在本地处理，联网后自动回传服务器，同时保留电脑上原有文件与本地数据。

“只放表格”在软件内部体现为 SQLite 指标缓存、表格和配置；程序运行时、日志及模型资源仍是必要文件，不能把软件数据目录当成只有 Excel 的文件夹。

## 部署结构

- 服务器：Windows 10 x64，独立 CPython + FastAPI + SQLite WAL + 本地任务队列 + 原有 React/Plotly 前端。
- 任务计算在子进程执行，不需要 Redis、PostgreSQL、Docker 或硬件虚拟化。
- 常驻：Windows 任务计划程序，开机触发、LocalService 账户、无限运行时长、失败后重启。
- 桌面端：本包的 Electron 程序 + 独立 Python 本地后端，只监听 127.0.0.1，保留原有菜单、图表工作区和本地数据能力。
- 内网访问：服务器默认监听 0.0.0.0:8000；防火墙只放行指定办公网段。

原始数据上传入口是在服务器上运行的浏览器。远程桌面进入服务器后，打开 http://localhost:8000 并选择服务器磁盘上的文件；选择个人电脑浏览器里的文件会从个人电脑上传，不会自动读取服务器磁盘。

## 双向同步协议 v2

服务器为每个实例保存持久 UUID。每个批次有修改版本；SQLite 触发器在批次、器件、文件目录、对照表变动时更新版本，因此批量计算的 SQL 写入也能被识别。

1. 客户端获取完整批次目录及各批次版本。
2. 只下载新增/变化的已完成批次；正在上传、重算或失败的批次不覆盖可用副本。
3. 元数据和指标在一致的数据库读事务中导出；本地每批次提交。
4. 本地使用远程 ID 到本地 ID 的映射，更新指标时保持现有器件 ID。
5. 完整目录确认删除后，才删除对应的服务器副本；网络失败不推断删除。
6. 同名本地原始批次不会被覆盖，冲突会显示在同步面板。
7. 启动、联网事件、前台激活和每 60 秒尝试同步；重叠请求受锁保护。
8. 服务器 UUID 改变时停止混合同步。换服务器应保留原服务器数据库身份，或先备份并使用新的个人数据目录。
9. 独立对照表即使未被批次引用，也会上传解析后的条目，并从服务器同步给其他电脑；同名不同内容时报告冲突，不覆盖服务器数据。
10. 软件端已完成处理且未回传的本地 SNP/ZIP 批次自动排队上传。上传与服务器处理成功后才标记同步；失败保留本地文件并在下次联网时重试。

### 表格上行

电脑导入 XLSX/XLS/CSV 后，已解析的指标通过内网回传。服务器记录“客户端 UUID + 本地批次 ID”的回执与内容摘要。请求重试不会生成重复批次，也不会默默覆盖同名不同数据。

两种模式：

- 独立指标批次：关联字段留空，服务器创建新的共享指标批次，其他电脑能同步。没有对应原始测量文件的表格不能凭空生成真实频谱。
- 关联已有原始批次：先同步原始批次，上传表格时填写准确的服务器批次名。按原始文件名、端口及可用目录信息唯一匹配，更新指标并保留原始路径。去嵌状态必须一致；服务器版本变化、文件重复或匹配缺失时拒绝覆盖，要求先同步后重新导入。

不以“器件数量相同”授权删除原始文件。自动和手动原始批次回传均保留本地原始文件。

## 完整绘图与文件访问

保持现有 Plotly 绘图、统计分析、筛选、缩放、导出、工作区及本地模式。
服务器副本的请求通过本地后端转发：

- S11 幅度、S11 相位、实部/虚部、Z11 幅度和相位；
- BodeQ 原始/平滑/拟合曲线；
- 原始文件列表、文件级曲线、文件树；
- 单文件、文件集合、文件树和批次下载；
- 服务器批次的文件操作、重算与对应任务查看。

文件树节点和任务使用与本地隔离的编号，避免把服务器 ID 当成本机 ID。
远程曲线按真实原始文件计算；传输不默认降采样。历史 gzip SNP 下载时恢复原始文件内容。

保留已有代理模型功能并随包包含仓库现有模型资源。实验性的“Z-稀疏重建”入口也保留并可远程调用，但当前仓库没有该功能所需的 sparse/reconstructor.pt 权重；它会如实显示模型缺失，不能声称已补出该模型。S11/Z11/相位/BodeQ 的真实数据绘图不依赖这些权重。

## 运行、恢复与数据边界

- 默认保留原始 ZIP，不自动清除服务器原始 SNP。
- 进程重启后，中断的任务明确标为失败并提示重新提取/重算，避免永远停在“处理中”；保留输入，不自动重放可能部分完成的科学计算。
- 后台日志轮转；提供健康检查、停服备份和升级脚本。
- 数据库高于程序支持版本时拒绝降级，不能通过删表“修复”。
- 内网客户端显式绕过系统 HTTP/SOCKS 代理。
- 多人同时查询/绘图可用；写入由 SQLite 串行协调。没有未经实测的并发人数或曲线响应时间承诺。
- 现有平台没有完整的账号权限系统；Windows 远程桌面登录也不是平台权限。包按可信办公网共享平台部署，以防火墙网段限制访问，不应把 8000 暴露到公网。

## 验证范围

本次新增同步和代理逻辑有自动化测试，并使用两套真实 HTTP 原生服务验证无本地 SNP 的远程曲线、BodeQ、文件列表、文件曲线、下载与增量更新。

Windows 可执行运行时和离线 wheels 已纳入包并做依赖完整性/文件校验。构建主机是 macOS，因此 Windows 安装器、LocalService 权限、重启无人登录、真实办公 Wi-Fi 路由和大规模多人负载仍需按 DEPLOYMENT.md 在目标机器验收，不能用 Mac 测试代替。

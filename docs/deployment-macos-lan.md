# Mac 桌面版连接 Windows 内网服务器

本次 Mac 桌面版版本为 **0.3.2**，安装包面向 Apple Silicon（M1/M2/M3/M4 等，arm64）。配套服务器地址为 `http://172.20.9.160:8000`，服务器使用 20261012 Windows 原生部署包。

## 安装或替换旧版

1. 退出旧版 ALN 软件。打开 DMG，把 `ALN Resonator Data Platform.app` 拖到“应用程序”，同名时选择替换。
2. 从“应用程序”打开新版。不要同时运行旧版和新版。
3. 个人数据库、原始文件和对照表位于 `~/.aln-data`，替换应用程序后继续保留。首次打开新版会补充数据库的同步元数据，建议在退出软件后先备份这个目录。

DMG 仅包含程序和模型资源，不包含服务器或个人的 SNP 数据。本地构建的安装包没有 Apple 开发者公证；如果 macOS 提示无法验证开发者，可通过系统设置的“隐私与安全性”允许本次打开。

## 配置同步

进入“批次管理”，找到顶部的“内网服务器同步”，输入 `http://172.20.9.160:8000`，填写自己的上传人名称，点击“保存配置”，再点击“立即双向同步”。软件启动、联网、回到前台及每分钟会尝试自动同步。

这个输入框出现在桌面客户端；直接打开服务器网页时不显示。若软件中没有输入框，先在应用菜单的“关于”中核对版本是 0.3.2，确认打开的是“应用程序”中的新版应用。

## 文件与绘图

- 服务器批次同步到 Mac 的是指标和文件目录信息。查看服务器持有的原始数据曲线时，通过内网读取；S11、Z11、相位和 BodeQ 等原有绘图功能保留。
- Mac 软件上传表格或独立对照表后，其解析数据可同步到服务器和其他客户端。
- Mac 软件上传 SNP/ZIP 时保留本机原文件，处理完成后回传服务器；离线时等待恢复内网再重试。
- 只有服务器持有的原始曲线，需要连接办公内网。下载单个 SNP 或整批 ZIP 时主动选择保存位置。

## 连接问题

先在 Mac 浏览器访问 `http://172.20.9.160:8000/api/health`，应得到包含 `"status":"ok"` 的文本。若不可达，检查办公 Wi-Fi 与服务器之间的路由及防火墙；若 Wi-Fi 不属于服务器的本地网段，服务器管理员需按实际办公网段调整防火墙规则。

Mac 日志位于 `~/.aln-data/logs/backend.log` 和 `~/.aln-data/logs/electron-main.log`。同步有冲突时查看面板中的具体错误，先同步再处理，不能仅以本机上传成功作为服务器已收到的证据。

## 本次验证

前端类型检查通过，130 个测试通过、1 个跳过。使用打包后的 arm64 后端和独立测试服务器运行两项集成测试，验证 SNP/ZIP 上传及本地文件保留、表格与对照表双向同步、远程 S11/Z11/相位/BodeQ 曲线和原始文件下载。打包桌面应用在隔离数据目录中验证启动、健康检查、版本显示和同步地址保存。

这些测试使用测试数据和本机测试服务器；连接办公内网的 Windows 服务器后，仍需在同步面板查看同步结果并核对服务器上的批次。

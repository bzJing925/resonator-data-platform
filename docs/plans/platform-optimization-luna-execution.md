## 已消除的关键选择

| 问题 | 固定选择 |
| --- | --- |
| 跨端身份 | 持久origin UUID+源批次UUID+器件UUID；整数id保留本地兼容 |
| 处理历史 | 每次创建独立task/run，不重置旧task |
| 重算安全 | 独立staging，核验lease/revision后同事务发布，失败保留旧结果 |
| 一次上传两阶段 | prepare上传并检查→确认报告→commit消费draft，不重传 |
| 完整恢复 | IndexedDB完整版本指针与2000行块；撤销仅当前会话 |
| 多窗口冲突 | generation乐观锁，重载或另存，禁止静默覆盖 |
| 查询总数 | 未知明确null，lower bound不当精确总数 |
| 全筛选导出 | 独立ExportJob、源快照、流式读取，达到预算明确失败 |
| 静态导出限制 | 全筛选CSV≤200000行/100MiB，XLSX能力关闭，超限明确拒绝 |
| 删除 | 30天软删；本地移除与远端删除分开；同步显式tombstone |
| 表格冲突 | 保留原base revision，409后不自动修改revision重放 |
| 对比频段 | 已提取标量不能靠筛选改频段；必须同条件结果或重算 |
| 报告 | 冻结已保存版本、自包含PNG HTML、浏览器打印PDF |
| 凭据 | 第一版仅会话输入，不增加凭据IPC |
| 模型验证 | 读取已存在产物；没有指标显示未知，不新训练或编造 |

## 模式验收矩阵

| 运行组合 | 必验内容 | 能力限制 |
| --- | --- | --- |
| PostgreSQL服务器+Celery/Redis | 上传/重试/取消竞争/发布/导出/迁移/同步协议 | 要真实服务，mock不足以验收 |
| native SQLite服务器+本地执行器 | 同流程、WAL双连接、停止、同步v3 | mode=server且database=sqlite |
| Electron桌面+SQLite | 旧库升级、重启恢复、文件访问、与真实源端同步 | 不用模拟browser reload替代进程重启 |
| 无后端静态版+DuckDB | 发布快照查询/项目保存/快照比较/限定完整CSV/报告 | 无上传、任务执行、回收站、双向同步、远端删除 |

前端单元测试验证规则，真实Playwright验证IDB/Plotly/离线报告，真实数据库双连接验证原子性和并发。新增E2E测试文件统一放frontend/e2e/analysis，已有playwright.config.ts已限定该目录；命令按文件名过滤，不使用错误的analysis/双层路径。

- 不覆盖已存在在途改动；需要改脏文件时只做职责明确的增量，先对照基线。

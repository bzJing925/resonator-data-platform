# P7：小面积 PF Qp 偏差建模受控实验协议

2026-10-26。在新增实验代码运行前冻结。P6E–P6I 排除了标签敏感性、raw 提参、去嵌配对、坐标构成与 BodeQ 拟合噪声五类解释后，对剩余的小面积 PF Qp 外层低估做有边界的偏差建模实验。全部结果为已见数据上的回顾性研究，不是新盲测，不解冻任何 P3 模型/划分，不发布模型。

## 背景与已排除解释

面积两端留出（训练不见 700/5500 μm²）中，700 μm²、PF=1、EG=0 的 8 个结构（G1-1…G8-1，FL=0…2）Qp 全部漏覆盖且全部低估：P6A GP 误差 −204.55…−72.02，P6C 所选 trend_gp_log_area MAE=118.761，两种联合区间均 0/8。

已排除（详见各轮文档）：

- P6E：单坐标删除不能恢复覆盖；标签非个别异常点驱动；raw/de 配对差值中位 +6.9…+31.6，不是全部偏差的来源。
- P6F/P6G：raw Qp 重提参与原表一致（5.8e-13）；original/vz 配对重算 de Qp 与旧标签 125/125 一致（2.7e-11）。"去嵌不可复现"排除。
- P6H：与 900 μm² 组在 FL 配对共享坐标上 Qp 几乎相等（合并比值中位 0.978）；结构级表观差距由坐标构成主导。Qp 与 Qs/k²/fp 的组间行为解耦（共享坐标上 Qs −154.7、k² +0.69 个百分点、fp +14 MHz 而 Qp 不动）。900 组 164 条标签随后也通过 original/vz 核验。
- P6I：BodeQ 微差为优化器终止级环境噪声，与 Qp 无关。

剩余现象：位置匹配意义上 Qp(700)≈Qp(900)，但模型按训练段（900…5000）的面积趋势向 700 外推得到显著更低值。训练内代理已存在：P6D 面积伪边界 area_low=900 单元上所选配方 Qp MAE=43.761。

## 固定实验臂

只动模型/选择规则中明确列出的部分；GP 核、趋势 Ridge、四配方、划分、校准秩规则全部沿用 P6A/P6C/P6D，不新增超参数搜索。

- **A0 控制**：trend_gp_log_area。复用 P6C 四折内部预测与 P6D 压力预测文件，按 rtol=1e-12 校验后作为对照，不重拟合。
- **A1 边界平坦趋势**：与 A0 相同的趋势+GP，唯一改动是预测时把趋势分量的 log area 输入截断到该分支训练折内已见面积范围（缩放空间 [0,1] 之外截到端点）；GP 残差输入不截断。假设：900 以下的线性趋势外推是偏差来源，边界平坦化是保守先验。
- **A2 逐目标配方选择**：P6C 四配方不变，选择粒度从每 scope 一个配方改为每 (scope, target) 一个配方；Qp 允许与其他目标不同。仅用 P6C/P6D 已保存内部预测计算，不新拟合。
- **A3 分支×面积残差偏移**：A0 之上，对训练折内每个 (branch_id, area_um2) 单元的结构平均 log 残差按 n/(n+4) 收缩（k=4 冻结）后加回预测；训练折未见的面积水平偏移为 0。检验分支偏差在训练内的可学习性；对外层 700 预期无效，作为负面对照，用于区分"偏差存在但不可外推"与"偏差不存在"。

## 训练内验证与选择（冻结）

- 内层验证 1：P6C 四折 design_group 隔离 CV（沿用 P6C 折分配文件，逐 scope）。A1/A3 新算，A0 复用校验。
- 内层验证 2：P6D 伪边界机制，仅面积轴 area_low/area_high 两个 scenario（其余轴本轮不涉及）。A1/A3 新算，A0/A2 复用 P6D 文件。有效性沿用 P6D 容量规则：分支内 ≥3 个轴水平、移除边界设计组后 ≥2 个训练组、训练侧 ≥2 个水平。
- **主指标（冻结）**：target=qp、branch ∈ {pf1_eg0_fl0, pf1_eg0_fl1}、scenario=area_low 的全部有效 (scope, branch) 单元上，先对设计组求平均绝对 log 误差，再对单元等权平均。
- **约束指标（冻结）**：P6D balanced 分数（四折 CV，分支×目标单元等权平均）。所选臂相对 A0 恶化不得超过 5%。
- **成功判据（冻结）**：主指标相对 A0 改善 ≥20% 且满足约束 → 选该臂；多臂达标取主指标改善最大者，并列取臂编号小者。无臂达标 → 保留 A0，全部臂按负面结果报告。A2 参与同一比较（其单元预测 = 逐目标内部 CV 所选配方的预测）。
- 指标出现 NaN/无效单元按 P6D 规则跳过并记录原因；不允许事后改阈值、改臂定义或改指标。

## 外层报告（回顾性，不作选择依据）

selection.json 在任何外层标签读取之前保存。其后：A1/A3 在各 scope 的完整外层拟合集重拟合并按 P6C 两种方式校准（joint_global / joint_scaled，calibration 仅校准）；A0/A2 外层直接复用 P6C 保存预测。报告全部臂的外层 test 四目标 MAE、联合覆盖/宽度、small_area_pf_qp 8 结构误差与命中。外层数字只作回顾性描述，不作为选择依据；不因外层结果调整任何内部规则。

## D1 位置构成诊断（描述性，无模型）

对 pf1_eg0_fl0/pf1_eg0_fl1 每个结构：在同分支同面积水平内取 ≥80% 结构共有的坐标子集（冻结阈值），计算该子集上的坐标中位数标签与原全部坐标标签的 log 差；报告全分布；对 8 个外层目标结构比较该敏感性与模型残差的量级。若标签构成敏感性远小于残差，坐标构成不能解释外层失败（与 P6H 一致），反之则需把标签构成列为新候选。此诊断不改动任何标签，只读 P3 records/structures。

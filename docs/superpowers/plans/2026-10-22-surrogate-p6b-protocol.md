## 假设与可证伪检查

1. 小面积 PF 有校准/测试残差分布不一致：使用原模型与划分，分别导出 calibration/test 的标准化 log 残差、符号和分支统计，核对实际联合阈值。报告小样本数，不作覆盖保证。
2. 实测离散性：关联 P3 结构表的 Qp 位置 MAD、坐标数、P10/P90 和结构中位数置信区间；比较覆盖/未覆盖及 PF 分支，不把相关性当成因果，不用观测置信区间替代预测区间。
3. 扫频量化：只对冻结 fs/fp 各自邻域三个点的 log|Z| 做抛物线顶点插值，顶点必须在相邻采样范围内、曲率方向正确。不换峰、不拟合真实标签。比较原始与插值后的 EG/fp/k² 方向，同时列出相邻变化相对频率步长的大小。亚采样变化仍不代表物理分辨率或网格收敛。
4. 峰选择敏感性：列出所有实际局部极值，诊断 prominence≥1 dB 的竞争峰，比较所选峰与其他候选的幅度差；≤3 dB 只作竞争警示。相邻尺寸从前一点选峰出发，匹配最近频率的候选峰，记录与独立主峰选择的差异；这是连续性检查，不能证明相同物理模态。

额外检查 EG 边界 GP：从已保存的模型读取训练均值、测试点与训练点的最大信号核相似度及最近距离，比较预测向训练均值收缩的程度；不改变核参数，不按 test 搜索新的 length scale。

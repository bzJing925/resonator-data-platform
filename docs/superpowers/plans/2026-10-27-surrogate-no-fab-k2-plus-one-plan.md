# 无新增流片的 k² 外推寻优执行计划

日期：2026-10-27。
状态：计划稿。用户已确认目标口径。本轮不执行训练或候选搜索。

**1. 目标与约束**

目标：预测尚未实测的结构性能。
主目标：k² 比当前实测基线高至少 1 个百分点。
用户已确认采用绝对提升，不采用相对提升。

| 项目 | 数值 |
|---|---:|
| E1-1 的 k² 实测典型值 | 14.6744702842% |
| k² 目标 | ≥15.6744702842% |
| P1203 当前 GP 预测 | 15.6397821240% |
| P1203 距目标的差值 | 0.0346881601 个百分点 |
| P1203 当前 ExtraTrees 预测 | 14.454018%左右 |

程序读取完整精度的基线再计算阈值。
页面可显示四位小数。
程序不得用显示舍入值作达标判断。

硬约束如下。

- 不安排新增流片。
- 不把独立实测作为本计划的执行依赖。
- 不要求新增 COMSOL 求解。
- 保留 P3 划分、冻结模型及全部失败对照。
- 不把已经查看的 test 称为新盲测。
- 不混合 raw 与 de 训练样本。
- 不把仿真性能当成实测训练标签。
- 不猜测 AG、层厚、特殊拓扑或制造步长。

本计划交付计算预测。
本计划不能保证未测器件的实际 k² 提升 1 个百分点。
没有新增实测时，所有候选保留“未实测”标记。

**2. 固定术语**

| 术语 | 含义 |
|---|---|
| 实测基线 | E1-1 的 k² 实测典型值。 |
| 点预测 | 一个模型给出的性能数值。 |
| 边界检查 | 用较小的已测范围拟合，再预测留出的已测边界。 |
| 计算保守值 | 综合模型分歧和历史误差得到的筛选数值。 |
| 候选结构 | 未在实测目录中出现的结构参数组合。 |
| 目标差值 | 候选 k² 预测值减去实测基线。单位为百分点。 |

计算保守值不是具有已验证覆盖率的置信下界。
多个模型一致也不等于实际性能已经得到验证。

最后进行一次有界搜索。
不以“必须出现达标数字”为模型选择规则。

**4. P13B：先检查现有峰**

P1203 的参数是 EG=3.0 μm、FL=0.025 μm、面积=5500 μm²、PF=0。
现有 PF=0 正 FL 分支的最小实测 FL 是 0.5 μm。
FL=0 使用另一个分支模型。
因此，P1203 同时涉及 EG 外推和正 FL 分支下缘外推。

审计执行四项检查。

1. 分别画出 FL=0 和 FL>0 的预测剖面。
2. 检查 FL 从 0.5 减小到接近 0 时的预测变化。
3. 分开记录 GP 的趋势项和残差项。
4. 检查邻域参数扰动是否让超标信号消失。

不能默认 FL=0 与 FL>0 的物理结构连续。
不能默认两个分支必须存在物理跳变。
只有结构资料或可核实的仿真支持时，才施加跨分支约束。

现有连续峰约为 15.663%，仍低于目标。
加密网格只能定位模型峰。
加密网格本身不构成更高性能的证据。

**5. P13C：只增加两类模型方案**

对照模型保持冻结：P3 ExtraTrees 与 P6C GP。
ExtraTrees 保留为域外分歧对照。
不把 ExtraTrees 超过目标设成强制门槛。
树叶均值模型通常不能突破其训练目标范围。

新方案 M1：几何参数直接预测 k²。
采用低复杂度的正则化加性模型。
分开处理 FL=0 与 FL>0。
检查线性尾部与原 GP 尾部的差异。
只有证据支持时才加入跨分支约束。

新方案 M2：几何参数预测频率，再计算 k²。
输入只包含已知结构参数。
实测 fs/fp 只能作为训练监督。
未测结构的推理不得读取实测 fs/fp。
模型必须保持 fs>0 且 fp>fs。
k² 使用项目现有提参公式。

M2 必须先检查统计口径。
逐记录计算 k² 后取中位数，与中位频率代入公式可能不同。
M2 必须与 P3 典型值口径对应。
若不能对应，M2 只能作为旁证。
不得通过更换目标统计口径获得提升。

仿真规律只作条件性软约束。
先核对几何定义、层厚信息及峰的连续性。
保留 P6A/P6B 的非单调反例和峰切换记录。
不施加“EG 越大，k² 必然越高”的全局规则。
无法核实可迁移条件时，不启用仿真约束。
若启用，M1 增加一组有约束/无约束消融。
仿真 k² 与 Q 均不成为实测拟合样本。

**6. 模型选择与评价纪律**

保持原有训练、校准和测试成员不变。
在各既定拟合集内部进行设计组隔离。
同一设计组不得同时进入拟合折和评价折。

主要检查 EG 上边界。
同时检查 FL 下边界及 EG/FL 联合边界。
留出多个 EG 水平时，必须记录剩余水平数量。
现有正 EG 只有 0.75、1、1.5、2 μm 四个水平。
样本不足的检查单元不能当成通过证据。

本计划建议冻结以下新模型接受条件。
这些条件只用于 P13，不追溯修改 P7—P12。

- PF=0 的 k² 边界 MAE 比同口径 P6C 对照降低至少 10%。
- 普通组隔离评价的 k² MAE 恶化不超过 5%。
- 最差有效边界单元的平均绝对误差恶化不超过 5%。
- 不出现非有限值、无效频率或非法结构输入。
- 完整报告各单元的数量、误差与高估方向。

记录“预测提升 ≥1 个百分点，但留出实测未达标”的误报。
误报只作当前回顾证据。
若没有可评价的提升事件，明确记录样本不足。
不能把零事件解释为零误报风险。

先保存模型选择，再读取外层结果。
外层结果只作回顾性报告。
所有数据此前已用于分析，因此本轮没有新盲测。
不得因为某个模型预测更高而选择该模型。

**7. P13D：冻结搜索范围**

第一轮保留 PF=0、面积=5500 μm²。
EG 范围保留 0–3.0 μm。
FL=0 单独搜索。
正 FL 的主搜索范围为 0.5–2.0 μm。

0<FL<0.5 μm 单独列为支持不足区域。
该区域保留 P1203 作为审计对照。
该区域的候选不能仅凭点预测进入保守推荐名单。

只做一次 EG 扩展评估：3.0–4.0 μm。
不得因为尚未达到目标而继续扩大 EG。
EG 延长线曾出现约 15.83% 的 GP 预测。
这个数值只能作为搜索线索。
它不代表双模型认可或实际性能改善。

每个候选记录标准化外推距离。
比较该距离与训练内边界检查的距离。
若超出可检验距离，候选标为高风险计算假设。
没有对应边界证据时，不报告有覆盖率含义的区间。

面积=4500、5000 μm² 只作稳定性对照。
不扩展至面积>5500、PF=1 或未知拓扑。
候选必须与实测目录中的参数组合不同。
没有制造步长资料时，只能称为计算结构。

**8. P13E：达标分级与停止条件**

对每个合格模型，保存设计组重采样后的预测分布。
有逐坐标记录时，同时做坐标块敏感性检查。
不把坐标离散度直接当作仪器重复性。

候选与基线采用同一轮重采样计算目标差值。
基线固定为 E1-1，不在每轮重新挑选冠军。
每个模型取目标差值的第 5 百分位。
再减去相应训练内边界的正向高估余量。
高估余量定义为 max(0, q95(预测 k²−实测 k²))。
误差单位统一为百分点。
只使用方向及分支匹配的训练内出折误差。
先在设计组内汇总，再计算第 95 百分位。
这样不会把负余量变成额外的预测提升。
各合格外推模型中最低的结果作为计算保守值。

模型集合必须在搜索前冻结。
每个模型、误差余量和外推距离均需可追溯。
至少两类模型通过评价，才可给出保守计算推荐。
本计划建议每个误差余量至少有 20 个独立设计组。
这些设计组须覆盖至少两个有效边界检查单元。
同一设计组的重复出折记录不增加独立组数。
每个设计组保持相同总权重。
若达不到上述数量，计算保守值记为不可用。
若候选超出已检查的外推距离，计算保守值也记为不可用。
该筛选方法不提供分布无关的覆盖保证。

数值邻域采用 EG、FL 各自偏移 −0.025、0、+0.025 μm。
面积与 PF 保持不变，共检查 9 个组合。
A 级要求全部 9 个组合的计算保守值均达到目标。
若组合越界或跨入未核实分支，A 级邻域条件不通过。
这些偏移只用于数值敏感性检查。
这些偏移不是制造公差。
上述数量及尺度须在 P13A 协议中冻结。

| 等级 | 判定 | 对外表述 |
|---|---|---|
| A：保守计算达标 | 计算保守值 ≥1 个百分点，且通过邻域敏感性检查。 | 计算证据支持预测提升至少 1 个百分点。尚无实测确认。 |
| B：点预测达标 | 至少一个合格模型达到目标，但 A 条件不满足。 | 点预测达标，模型分歧或误差余量不足。 |
| C：未达标 | 合格模型的点预测均未达到目标。 | 当前证据未支持目标。 |

只有边界跳变产生的超标点，另列为模型异常或支持不足假设。
不把这类点列为 A 或 B。

最多执行两类新方案、一次条件软约束消融及一次范围扩展。
若仍未达到目标，交付最高可支持预测和失败原因。
不得事后放宽阈值，或循环调参直到出现达标数字。

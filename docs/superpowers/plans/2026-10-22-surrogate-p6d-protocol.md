# P6D：训练内边界压力测试与选择规则冻结协议

2026-10-22。只比较选择规则，沿用 P6C 的四种固定配方与全部外层拟合/校准/预测；不修改核、趋势项、标签、外层划分或校准区间。仍属已见数据上的回顾性研究，不部署模型，仿真不参与拟合。

对每个外层拟合集构建六种内部伪边界：EG、FL、面积各自最低/最高已知水平。在每个拓扑分支内独立确定边界，只有至少 3 个该轴水平、移除边界所涉及全部 design_group 后仍有至少 2 个训练设计组且至少 2 个轴水平时，才形成有效单元。同组非边界结构设为 embargo，既不训练也不评分；不存在跨设计组泄漏。其余分支仍可用于各自模型拟合，但只评分该场景有效分支的边界结构。跳过单元按几何条件确定，对四配方完全一致，不因预测好坏跳过。

新增两种选择规则：

1. balanced_inner_cv：复用 P6C 四折训练内预测，先对结构/设计组求平均，再对分支与四目标单元等权平均，避免大分支支配。
2. minimax_pseudo_boundary（主压力测试规则）：每个场景/分支/目标计算设计组平均绝对 log 误差；按所有有效单元中最大误差最小选择，若并列再比较所有单元均值，再按 P6C 配方顺序。一个 scope 只选一个配方用于全部四目标，不拼接赢家。

输出三个选择策略（P6C 原策略及上述两种）的配方、内部证据、外层回顾性误差、区间共同覆盖与宽度、小面积 PF Qp。选择 JSON 必须先保存，才读取 P6C 外层预测用于报告。保留所有配方内部压力结果，不将较好外层表现倒灌选择。此轮也不声称处理了观测中位数不确定性；小样本最坏单元可能不稳定，必须报告其设计组数。

输出 optimization_p6d_20261022；所有代码在 ML worktree，本地 uv。原 P3–P6C 与既有 dirty 文件保持不变。验收：内部拟合、embargo、评估设计组严格隔离；跳过原因可复现；内部单元/分数独立复算；外层预测逐条与冻结 P6C 一致；测试及保存结果通过。新尺寸外推仍需要独立实测。

# P9：层级标签不确定性模型实验协议

2026-10-26。在新增实验代码运行前冻结。用户已批准立项：把坐标构成/位置离散显式建进标签不确定性。P3 划分、冻结模型与全部既有对照链维持冻结；P8 频率契约臂结论不变（保留 B0）。回顾性实验，非新盲测。

## 背景与授权说明

P6B/P6C 曾明确"不把位置 MAD 直接当 GP 噪声方差、不把观测 CI 重叠计作覆盖"——彼时无立项授权。用户现已批准以实验臂形式显式建模标签不确定性。P7 D1 量化了坐标构成敏感性上限（8 个目标结构 |Δlog| 中位 0.024、最大 0.249）；P3 structures.csv 提供逐结构逐目标的 `position_mad`（跨坐标中位数的 MAD，无缺失/负值）与坐标数。P3 协议同时提醒：坐标 MAD 不是中位数方差——本轮把它当作一个**冻结的离散度代理**，实验是否改善训练内区间行为，不作物理噪声解释。

## 固定定义

- 离散度代理（冻结）：`disp_i = {target}_position_mad_i / {target}_i`，逐结构逐目标，log 空间相对离散近似。
- 目标子集（冻结）：四个外层拟合集的 area_low 面积水平上、branch ∈ {pf1_eg0_fl0, pf1_eg0_fl1} 的全部结构（按 (scope, structure) 计评估单元）。

## 固定实验臂

- **C0 控制**：trend_gp_log_area + P6C 两种联合校准（joint_global / joint_scaled）。内部四折点预测复用 P6C 文件校验（rtol=1e-12）；为获得内部出折 log_scale 与外层 calibration 残差，按冻结配方重拟合（逐点与 P6C 校验）。
- **C1 异方差 GP**：与 C0 唯一差别是 GP 噪声项：去掉 WhiteKernel(0.05)，改为逐点 `alpha_i = 1e-10 + (disp_i / s)²`，s = 该分支拟合折内 GP 目标（log 残差）的标准差；核 Matern(0.5, nu=2.5, fixed) 不变；趋势 Ridge 不变；点预测 std 下限 0.001 不变。
- **C2 异方差校准**：点模型与 C0 逐位相同；仅改校准尺度——global 变体：校准分数 |Δlog|/disp，区间尺度 disp_query；scaled 变体：分数 |Δlog|/sqrt(std²+disp²)，区间尺度 sqrt(std_query²+disp_query²)。

## 训练内验证与选择（冻结）

- 内层区间评估（新机制，冻结）：每个外层拟合集做 P6C 四折组隔离 CV，取**出折预测**；对每条出折结构，用**其余设计组**（leave-one-group-out）的最大分数按 ceil((n_loo+1)·0.9) 秩求 90% 分位数，构造出折区间并判定覆盖。**逐目标分别进行**（不做四目标联合），global 与 scaled 两法分别计算；分位数在每个 scope 内计算，覆盖指标按 (scope, structure) 单元跨 scope 汇总。该机制只使用训练角色数据，是训练内校准评估，不是外层区间。
- **主判据（冻结）**：目标子集 Qp 出折区间覆盖（scaled 变体）相对 C0 提升 ≥25 个百分点（绝对）。
- **约束（冻结）**：balanced 覆盖（分支×目标单元等权，scaled 变体）相对 C0 下降 ≤5 个百分点；目标子集中位区间半宽 ≤ 2×C0；C1 另须满足点预测约束——P7 主指标（stress area_low PF qp）与 balanced 分数相对 C0 恶化 ≤5%（C1 改点模型；C2 点模型不变自动满足）。
- **选择**：达标臂中取目标子集覆盖最高者，并列取中位半宽小者；无达标 → 保留 C0，全部作负面结果。
- 指标 NaN/无效单元按既有规则跳过并记录；不允许事后改阈值、公式或子集定义。

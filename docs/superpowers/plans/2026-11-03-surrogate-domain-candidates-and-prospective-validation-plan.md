### D01：冻结公平比较契约

至少列出以下方法：B内层选定模型、P3 ExtraTrees方法、P6C trend_gp_log_area方法、同折常数基线。

区分“方法”与“历史权重”：旧全量权重可能见过当前测试结构，不能直接拿它评分。只有训练ID与本轮split严格兼容的折模型才能参与公平比较；不兼容旧权重仅作历史展示，不计胜负。

逐目标、逐scope对齐population、训练/测试ID、目标标签版本、单位、有效样本及分支。主集为primary，敏感性只作并列影响检查。模型的选择继续使用已冻结B内层选择，禁止用D外层结果再选赢家。

优先级：已有同折预测 → 已保存的同折模型推理 → 确实缺失的固定配置补拟合。不得重做B的720次拟合。若需补拟合，先登记缺失model/target/scope唯一清单、固定配置及数据哈希；仅补列表中的项目，不新增超参数/种子/模型族。

如果B所选模型就是P6C同配置，则明确两者是同一个方法；不将其一致性当成独立双模型证据。

输出availability.csv，字段至少：population/scope/target/model、预测可用、模型可用、训练ID匹配、是否需补拟合、原因。身份或训练集合无法证明一致时该比较为NOT_COMPARABLE，不硬凑结论。

### D02：生成可比较的误差表

在共同可评分结构集合上逐项输出：n、MAE、RMSE、bias、绝对误差P90、最大误差、每结构误差差值、优于/劣于另一方法的结构比例。同时保留各自原生样本集指标及共同样本丢失数，防止通过删困难样本改善结果。

核心目标k²/Qp分别评价；Qs/BodeQ独立呈现。k²单位为百分点，Qp无量纲；既报告原单位也报告相对误差，实际值接近0时相对误差标不适用，不能爆大后再静默删除。

主表比较模型方法，不以“较常数降低97%”作为结论标题。不做事后显著性宣称或假装未查看旧测试。若模型变化而标签不变，清楚说明差异来自训练配置/划分/算法，不能归因于中位数规则。

验收：共同样本真实值完全一致；预测只来自对应训练折；B原始结果未变。输出行级paired_predictions.csv，A4能独立重算指标。

### D03：生成按分支、方向和距离划分的支持地图

每个scope进一步按分支及可识别的同轴切片拆分：normal、EG上界、FL上界、面积下界、面积上界；700-PF必单列。报告测试独立design_group数，不把一个设计组的多个器件当独立外推证据。

每条记录包含：训练轴范围、留出水平、固定其余几何、外推距离、训练最近水平间距、n结构/n组、k²/Qp误差及偏差。不同scope重复出现同结构时分别报告，不汇总成更多独立样本。

**新D研究筛选默认预算，必须在D02计算新比较结果前写入comparison_contract，不是物理定律或旧验收门槛：**

- k²误差预算：0.25个百分点（目标改善1个百分点的四分之一）。
- Qp误差预算：相对误差20%；同时显示绝对MAE，不把相对误差掩盖为固定Q误差。
- 一个范围获得`SCREENABLE_RETROSPECTIVE`需：至少10个不同design_group；k² MAE≤0.25个百分点、|bias|≤0.125；Qp平均绝对相对误差≤20%、绝对平均相对偏差≤10%；两目标均不劣于同折常数基线；必需比较完整。
- n不足、某目标不通过或对应切片未测试则标`DIAGNOSTIC_ONLY`，不能靠相邻分支的总体PASS继承。
- 本门槛是在历史数据已被看过后的研究选择规则，不是新盲测认证；无论通过与否trusted仍false。不得在看到D结果后调松预算。

另保存同分支同方向结构级|error|的P90，名称`historical_error_margin`。它只是经验压力测试量，不叫95%预测区间、不宣称分布外覆盖保证。样本不足时值可显示，但不能用于晋级。没有数据支持的距离设为unsupported，不以线性放大误差条伪造保证。

输出domain_policy.json。D2只能消费该文件允许的范围，不能自行扩大。

## 8. D2：固定候选协议、有限搜索与拒绝

### D04：先固定目标、基准与制造约束

目标分别保存：

- `performance_candidate`：为k²改善目标筛选，要求Qp不劣于同批基准的预注册目标。
- `diagnostic_candidate`：用于检验模型外推/分歧，绝不能标成性能推荐。

性能基准：在已明确的同工艺、同拓扑及业务约束范围内，从主集结构中按k²中位数取最高者，平局依次按Qp中位数、structure_key排序；冻结其几何、标签和成员ID。若用户已指定基准则优先使用并记录。不能为了轻易达到+1而选较弱基准；不同工艺不可比时不得混合排名。没有可比基准时性能搜索为BLOCKED，但可完成诊断分析。

默认研究目标：k²增加≥1.0个百分点，Qp比值≥1.0；后者是本计划建议的“不牺牲Qp”约束，不冒称用户以前给过数值要求。执行时允许用户明确改成其他值，但必须在搜索前形成新协议版本，不能看完结果后改。

fabrication_inputs.json必含：允许工艺/拓扑/PF、EG/FL/AG/面积范围、可制造步长或可选值、关键尺寸容差、边界/连接约束、校准结构要求、是否已有版图。来源必须为现有设计资料或用户确认；不能把历史数据最小间隔当成制造精度。

制造信息缺失时，继续做`VIRTUAL_ONLY`研究候选，不生成“可下单/可制造”清单；D07保留输入缺口，不静默默认制造参数。

候选搜索规则：仅在已有拓扑和分支内进行。FL=0与FL>0分开，EG=0边界同理；不跨分支做连续插值。不探索新材料、厚度、AG未知水平或多轴同时越界。

### D05：研究推理边界与候选生成

先生成几何，再看性能，保持候选集合与输出排序确定性。

候选类别：

1. **MEASURED_CONTROL**：完整结构键匹配现有目录，仅作对照，从未测候选中排除。
2. **UNMEASURED_INTERPOLATION**：同分支、沿已测一维切片相邻水平之间的中点，其余参数固定，且具有真实相邻支撑。
3. **UNMEASURED_SPARSE_SUPPORT**：虽在各轴min/max内但缺少上述局部支撑；不冒称可靠插值，只作诊断。
4. **UNMEASURED_EXTRAPOLATION**：同分支单轴越界，其余参数取有支撑的已测切片；仅允许D03对应方向通过的范围。
5. **UNSUPPORTED**：未知分支、多轴越界、不可制造、无方向验证、超出允许距离或非法几何。

单轴外推候选默认仅两个增量：边界外0.5δ与1.0δ；δ取该分支该轴最近两个已测不同水平间距。要求至少3个已测水平，且外推距离不超过对应历史边界留出验证过的物理距离和相对间距倍数；如无可映射的切片验证，降为诊断。下界不得产生负EG/FL或非正面积，不跨0拓扑分支。容差与步长已知时先量化到合法制造值，再去重、重新分类和推理，不能先筛选后偷偷改变几何。

总几何预算最多50,000点，按完整结构键排序；超限时停止并报生成规模，不截取前50,000点制造排序偏差。每个模型/目标每点仅计算一次；不在结果出来后加密网格或加种子追峰。

**原研究包的outside_training_range拒绝必须保留。** 若确需外推诊断，新增独立D研究入口，调用已核验的底层冻结模型，但同时执行D03/D04白名单、单轴/距离/拓扑检查；所有返回结果标`UNVERIFIED_CANDIDATE`或`DIAGNOSTIC_ONLY`，不是更改原包支持声明。不能用except后继续预测、裁剪坐标、边界夹值或删掉原拒绝条件实现。

如果读现有CSV和模型即可完成D1，不为了统一CLI重新包装既有流程。补充代码的针对性验证一次覆盖：已测几何排除、端口/结构身份、单轴/多轴判定、边界0、未知分支、超距离拒绝、量化后重分类、旧预测接口拒绝行为未变。

### D06：筛选、排序和独立审查

每个点输出各目标预测、历史误差裕量、模型分歧、与冻结基准差值、支持类别/轴/距离、可制造状态、排除原因、模型与数据哈希。不只保存入选点。

研究压力测试分数（**不是统计置信下界**）：

- `stress_gain_k2 = prediction_k2 − baseline_measured_median_k2 − historical_error_margin_k2`。
- `stress_qp_ratio = (prediction_qp − historical_error_margin_qp_absolute) / baseline_measured_median_qp`。

历史基准测量不确定度尚未计入这两个分数，因此只可用于研究排序，不能证明性能提升。裕量必须来自对应D03范围，缺失则分数null且不通过性能筛选。

性能候选最低要求：D03允许，几何确实未测，k²点预测改善≥1.0且stress_gain≥1.0，stress_qp_ratio≥1.0，不触发几何/数值/物理必要条件拒绝。分歧大的模型不得通过平均值掩盖；没有独立方法证据标清单方法并仅作待验证候选。没有满足条件的点输出`NO_PERFORMANCE_CANDIDATE`，不放宽门槛。

最多选3个性能待验证候选：先stress_gain降序，再stress_qp_ratio降序，最后外推距离升序及structure_key排序；重复几何只选一次。最多再选2个诊断候选，优先已验证方向边界附近、模型分歧最大的点，并覆盖不同方向；诊断候选即使预测很好也不能混入性能推荐数。

标量必要检查：有限、正Q、0<k²<100%以及既有结构规则。四个标量模型无法验证复阻抗无源性或模态，不生成虚构阻抗曲线，也不写“已通过阻抗物理验证”。COMSOL没有运行就明确NOT_RUN，不用模型相互一致替代实验。

A4逐点检查完整结构键与576结构目录的匹配、范围/距离、模型训练来源、所有排除规则和排序。若搜索没有候选，检查全部拒绝原因和边界；负结果同样为执行PASS、科学候选结论REJECTED。

## 9. D3：独立实测协议v2

### D07：先区分实验要回答的问题

新文件写`D_RUN/measurement/measurement_protocol_v2.json`，旧C JSON不改。

实验组分别标注：

- 性能待验证组：D06入选，检验对固定基准是否达到+1个百分点及Qp要求。
- 外推诊断组：真正越出训练范围，检验指定轴/距离的预测误差；不预设达到性能目标。
- 未测插值组：检验新几何的范围内预测，不能作为外推证据。
- 已知结构复测组：评估新批次偏移、仪器与去嵌稳定性。
- 同批基准组：冻结的实际基准几何，必须在同批次同测量方案中取得新器件记录，历史值不能替代。

B1-6/A1-6可保留为重复性对照，不能作为新几何外推组；0.01848个百分点的预测差不构成+1目标候选。没有D06性能候选时，协议不得要求“验证已预测的+1提升”，可以只准备诊断/校准实验。

### 样本量与目标统计量

每个结构、每个参数：同器件重复测量先按冻结规则合并，再对全部独立器件等权取中位数；不取最好器件。重复测量不增加独立器件数。因参数缺失只影响该参数，不整器件删其他有效参数。

旧草案“每结构5器件、每器件3次重复”仅为操作草案，不继承为统计充分性保证。先冻结：目标误差容忍、改善阈值、置信水平、统计功效目标、候选数量及独立抽样单元，再设计样本量。

建议默认：单侧95%置信下界、功效目标80%；样本量依据新批次可用的先验重复性/器件差异证据进行设计，记录方法及假设。历史数据可用于规划，不能当新实验观测；没有独立重复/跨批次波动证据时标`SAMPLE_SIZE_UNRESOLVED`，可以先拟定独立先导实验，不宣称5个足够。

同一晶圆上的器件可能相关：协议必须说明独立单元是器件、位置簇、晶圆还是批次。若想跨批次推广，就需独立批次覆盖；只测一个批次只能形成该批次条件下的结论。重采样/区间方法须尊重簇结构，不能将所有重复当独立样本。

### 仪器、校准与盲测冻结

必填：器件几何/版图与工艺版本、晶圆/位置/端口ID、测量顺序、仪器型号与校准记录、功率、IFBW、温度、频率范围和步长、OPEN/SHORT身份、去嵌配方、提参代码版本、原始Touchstone及文件哈希。

频率步长应能分辨目标反谐振线宽；具体值依据预期fp/Q及仪器能力在测量前确定，不事后为高Q选最有利采样。各组采用同一冻结测量与提参流程，raw/de分开保存；缺校准证据则去嵌主结论为NOT_EVALUABLE。

先冻结模型/数据/候选及逐点预测，再接收性能结果；尽可能用匿名器件ID完成测量与提参。后续改结构、模型、基准、排除条件或样本规则都产生新协议版本；不能用已揭盲数据重新定义“独立验证”。

### 预注册验收：准确性与收益分开

1. **外推准确性**：以新结构所有器件中位数对冻结预测计算误差，按D03的预注册预算判定；逐目标逐轴逐距离报告。平均通过不能掩盖某一个必需结构/目标失败。
2. **+1个百分点收益**：差值为新结构k²中位数−同批基准k²中位数；预先固定方法计算单侧置信下界，要求下界≥1.0个百分点。点差≥1.0但下界不足，记证据不足。
3. **Qp约束**：按冻结比值阈值与相应单侧区间判断，不仅看点估计；默认阈值1.0的含义是不接受可证实的Qp退化，严格非劣判断仍须按预注册统计方法执行。
4. **多候选/多目标**：在揭盲前确定主要比较和联合成功事件；候选数量大于1时采用预定的多重比较控制，例如按主要比较数做Bonferroni。不能测完再只报告最好一个。
5. **区间方法**：在样本设计时确定适用于中位数差/比值及簇结构的方法和最低样本要求；不得将D06经验压力裕量当作此处统计区间。样本不足、不稳定或假设不满足则NOT_EVALUABLE。

这些是建议的前瞻验收规则，D07必须落成具体数值、方法、样本量和协议哈希后才可称READY_FOR_MEASUREMENT。缺实测条件仍可完成D07文档工作，状态为DRAFT_MISSING_INPUTS并列明最小缺项。

### D08：数字阶段封存

输出README.md、final_report.json、final_manifest.json，引用D1误差地图、D2全部候选/排除、D3协议及缺项。A4独立检查结论没有超过证据。

明确三个独立状态：数字工作是否完成、是否有性能候选、实测协议是否具备执行条件。没有候选和没有制造信息不是“模型已可信”，也不是必须无限训练的理由。

## 10. D4：拿到新数据后的步骤

### D09：接收独立原始测量

必须有D07冻结版本且预测先于测量揭盲。按真实外部文件边界核对器件身份、时间、哈希、样本数量、校准/去嵌记录、缺失与排除；保留全部原始记录，包括Fail和被排除记录。

只应用预注册无效规则，排除原因逐条列出；禁止因实测低于预期删器件、补测至显著或挑选重复。样本不足时按预注册短缺规则处理，不拿历史器件补足。

### D10：验收与适用范围更新

使用冻结模型和统计代码输出：每结构全部器件值、中位数、离散性、预测误差、区间、同批比较、Qp约束、校准诊断和所有失败项。

只有实际通过独立实测的分支/轴/距离/工艺条件可标PROSPECTIVE_VALIDATED。不会因此将整个模型global trusted置true；范围外仍拒绝。只完成旧几何新批次复测时只确认重复性，不确认新几何外推。

实测失败就保留失败结论。若用这些数据更新模型，它们成为训练/开发数据；下一次可信度验证需新的独立数据，不能在同一批结果上反复修模型后宣布盲测通过。

## 11. 失败与停止条件

| 情况 | 动作 |
|---|---|
| 同折旧方法模型/训练ID缺失 | 标NOT_COMPARABLE；只补冻结清单内必要拟合，不扩大训练 |
| D03方向不通过或样本不足 | 不输出该方向性能外推候选；可保留诊断候选 |
| 只有GP支持趋势、树模型范围外平坦 | 标single_method，不伪称双模型证实 |
| 新推理需要删除旧包拒绝检查 | 禁止；采用隔离研究入口或不做该预测 |
| 不清楚制造精度/约束 | VIRTUAL_ONLY；列具体缺项，继续不依赖它的分析 |
| 没有满足+1和Qp条件的点 | NO_PERFORMANCE_CANDIDATE，完整交付负结果 |
| 实验样本量或统计方法未确定 | DRAFT_MISSING_INPUTS，不宣称可正式验收 |
| 没有外部新测量 | D09/D10=NOT_RUN，封存D08 |
| 数据/模型/协议并行变化 | 停止受影响步骤，保护原文件，核对归属与依赖 |
| 针对性验证两次修复仍失败 | 报实际错误及最小阻塞，不继续扩张排障 |

# P6C：实测最小消融冻结协议

2026-10-22。P6A/P6B 后的回顾性实验，禁止称新盲测，不发布模型，不修改原始标签/划分。COMSOL 不参与拟合或伪标签生成。

固定四种配方：原 P6A GP（控制）；仅将面积换成 ln(area)；原坐标上的 Ridge(alpha=1) 趋势加 GP 残差；ln(area) 上的同样趋势加 GP 残差。每个拓扑分支、每目标独立拟合；输入 min-max 只读拟合折，GP 完全沿用 P6A 固定 Matérn 参数，不优化核。趋势拟合 log(y)，残差通过 exp(log(y)-trend) 送入同一 GP 实现，预测将 log 趋势加回。GP 标准差不包含趋势参数不确定性，不宣称为完整贝叶斯后验。

普通留出可用 train+validation，三种边界仅用 train。每个外层拟合集，按分支将 design_group_id 以 SHA256("P6C-20261022:"+id) 排序、轮转分配到 4 折，整组留出。只用这些训练内预测选择配方：每结构四目标平均绝对 log 误差，再在设计组内平均、对所有组平均。每 scope 选一个配方，四目标共用；分数相同按上述配方顺序选。不会按外层 test 选分支/目标赢家。保存全部内部预测、分组和分数。

冻结选择后，各配方在完整外层拟合集重拟合。calibration 仅校准：分别报告设计组四目标最大绝对 log 残差的全局联合区间，以及沿用 GP 标准差归一化后的联合区间；两种方法都用 ceil((n+1)*0.9) 秩。这样可分别观察点模型变更与区间归一化影响，不将覆盖率改善全部归功于模型。n 不足时不产生有限区间。

外层 test 只报告回顾性误差/覆盖/宽度及小面积 PF Qp，保留四种配方全部结果和 P3/P6A 对照。所有输出 trusted=false。观测中位数 CI/MAD 不直接当噪声方差，相关建模另列为未完成。没有制造约束或独立新实测时不生成可下单新尺寸。

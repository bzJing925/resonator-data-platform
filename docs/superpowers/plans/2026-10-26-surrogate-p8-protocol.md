# P8：频率特征契约实验协议

2026-10-26。在新增实验代码运行前冻结。用户已明确授权改变"未测结构可预测"契约：允许引入 fs/fp 实测派生特征，模型适用场景变为"该结构已有实测频率"。P3 划分、冻结模型与全部既有对照链维持冻结。回顾性实验，非新盲测。

## 背景与先验证据

P7 证明：700 μm² PF(EG=0) 8 结构的 Qp 外层低估不是趋势斜率、配方粒度、可收缩分支偏差或坐标构成所致；失败收窄为"该结构的 Qp 水平超出 [EG, FL, area] 特征面的拟合值"。频率特征实验的动机：实测 fs/fp 可能携带几何特征缺失的信息。

协议前只读先验检查（P3 结构表，不训练任何模型）：8 个目标结构的 fp 比同 FL 同分支的大面积同伴中位数低 217–313 MHz，**恰好落在分支面积趋势上**（分支 fp 随面积单调上升：4.5508→4.6225→…→4.8808 GHz）；而 Qp 在 700 处逆势上行（fl1 中位 485.7@700 vs 385.0@900，900→5500 段单调上升）。训练段内 fp 与 Qp 同向变化，因此频率特征在趋势意义上预期**不能**修复该失败，甚至可能加深低估。本实验是按协议执行的冻结证伪检验，预期负面结果同样交付。

## 固定实验臂

- **B0 控制**：P7 A0（trend_gp_log_area，几何三特征）。复用 P6C/P6D 保存的内部/压力预测，rtol=1e-12 校验，不重拟合。
- **B1 频率条件模型**：与 A0 完全相同的趋势+GP 结构、核参数、Ridge alpha、log 目标，唯一改动是特征向量从 [eg_um, fl_um, log(area_um2)] 扩为 [eg_um, fl_um, log(area_um2), fs_ghz, fp_ghz]；min-max 缩放仍只读拟合折。B1 全部输出标注 `contract="measured_frequency"`，适用场景变为"该结构已有实测频率"；k² 在该契约下近似 fs/fp 的确定性函数，其指标近退化，单列说明，不与几何契约混比。

fs/fp 来源为 P3 冻结 structures.csv 的结构典型频率（全部 576 结构有限值，已核验）。不新解析曲线、不改标签。

## 训练内验证与选择（冻结，与 P7 同构以便比较）

- 内层验证 1：P6C 四折 design_group 隔离 CV（沿用 P6C 折分配文件，逐 scope），B1 新算。
- 内层验证 2：P6D 机制的面积轴伪边界（area_low/area_high），B1 新算；有效性沿用 P6D 容量规则。
- **主指标（冻结，同 P7）**：target=qp、branch ∈ {pf1_eg0_fl0, pf1_eg0_fl1}、scenario=area_low 的全部有效 (scope, branch) 单元，设计组平均绝对 log 误差再等权平均。
- **约束指标（冻结，同 P7）**：P6D balanced 分数（分支×目标等权）。
- **成功判据（冻结，同 P7 阈值）**：主指标相对 B0 改善 ≥20% 且约束恶化 ≤5% → 选 B1，否则保留 B0。
- 指标 NaN/无效单元按 P6D 规则跳过并记录；不允许事后改阈值。

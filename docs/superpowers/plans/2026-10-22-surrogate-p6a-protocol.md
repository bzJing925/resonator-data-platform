## 固定新增方法

- 每个拓扑分支独立拟合 `[EG, FL, area]`，拟合折 min-max 缩放，常数维 scale=1，目标取自然对数。
- `ridge_log_global`：Ridge(alpha=1.0)，截距开启。全局绝对 log 残差按设计组取最大，再用 ceil((n+1)*0.9) 秩校准，与 P3 区间单位一致。
- `gp_matern_scaled_marginal`：GaussianProcessRegressor(normalize_y=True, optimizer=None, alpha=1e-10)，固定 Matern(nu=2.5, length_scale=0.5) + WhiteKernel(noise_level=0.05)，所有 kernel bounds=fixed。噪声参数为归一化 log 目标方差尺度；不从测试集估计，不作超参数搜索。预测 log 标准差取 max(return_std, 0.001) 供残差标准化，白噪声包含于该标准差中。逐目标独立校准设计组最大标准化 log 残差。
- `gp_matern_scaled_joint`：复用同一 GP 点预测；校准分数为每个设计组全部结构、四目标的最大标准化 log 残差，共用一个 90% 有限样本分位数。计算点预测 exp(log_mean)，它是条件 log 中心，不声称算术条件期望。
- 样本不足使分位秩超过 n 时，不生成有限校准区间；未知分支返回缺失。保留范围外预测但明确支持标签，不开放可信排名。预测不作迎合标签的剪裁，报告 k² 越界等物理失败。

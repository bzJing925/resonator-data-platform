# P10：子集异方差区间 + 仅 Qp 频率子模型实验协议

2026-10-26。在新增实验代码运行前冻结。用户已裁决 P8/P9 遗留项：接受"仅目标子集启用异方差区间"（其余严格维持 C0/P6C 冻结行为）；频率特征仅用于 Qp 子模型；页面"仅报告"显示待本轮结果后另行实施（本轮不做产品改动）。一轮含两个独立子实验：二者共享冻结输入与训练内验证纪律但机制不同（区间装配 vs 特征契约），合并为一轮以减少协议开销；任一子实验的选择不影响另一个。回顾性实验，非新盲测。

## 实验一：子集异方差区间

**目标子集（冻结几何规则，不用任何标签）**：branch ∈ {pf1_eg0_fl0, pf1_eg0_fl1} 且 area_um2 == 700 的结构。内层评估中该子集只存在于结构留出/EG/FL 三个拟合集（area_edges 拟合集无 700 水平，记 subset_n=0 并说明）。

**臂（冻结）**：

- **D0 控制**：P6C trend_gp_log_area 点预测与区间，逐位复用（经 P9 校验过的产品文件，rtol=1e-12）。
- **D1 保守臂（用户指定优先）**：点预测逐位等于 C0；仅子集行的区间尺度换为 sqrt(std² + disp²)（disp 为 P9 冻结离散度代理），分位数沿用 C0 同一共形分位数；非子集行点预测与区间逐位等于 D0。
- **D2 对照臂（子集切换）**：子集行的点预测与区间整体换为 P9 C1（异方差 GP），分位数用 C1 自己的共形分位数；非子集行逐位等于 D0。

**训练内验证（冻结）**：内层沿用 P9 机制（四折组隔离 CV 出折预测 + 逐目标 leave-one-group-out 共形 90% 分位数，分 scope 计算分位数、按单元汇总），全部输入为 P9 已保存的出折预测（本轮只做装配与评分，不新拟合内层模型）。

**判据（冻结）**：

- 主判据：子集 Qp scaled 覆盖相对 D0 提升 ≥25 个百分点。
- 宽度上限：子集中位 scaled log 半宽 ≤ 4× D0（子集局部替换，放宽于 P9 全局 2×；理由：非子集零变化由结构性校验保证，宽度代价仅限子集）。
- 非子集零变化：非子集行的点预测与区间上下界逐位等于 D0（结构性校验，必须 100% 通过）。
- 全局约束：balanced 覆盖（分支×目标等权）相对 D0 下降 ≤5 个百分点。
- D2 另须点守卫：P7 式主指标（stress area_low PF qp）与 balanced 点分数相对 D0 恶化 ≤5%（D1 点不变，自动满足）。
- 选择：D1 达标优先选 D1；否则 D2 达标选 D2；否则保留 D0。多达标不发生时按此优先级，不比较 D1/D2 间优劣。

## 实验二：仅 Qp 频率子模型

**臂（冻结）**：

- **F0 控制**：全部四目标几何契约（= B0 = P6C trend_gp_log_area），复用 P6C/P6D 保存预测。
- **F1**：仅 Qp 换为 P8 B1 式五特征模型 [EG, FL, log area, fs_ghz, fp_ghz]（`contract="measured_frequency"`），其余三目标维持几何契约（`contract="geometry_only"`）。k²/Qs/BodeQ 不被新契约拖累。

**训练内验证（冻结，与 P7/P8 同构）**：内层四折 CV 与面积轴伪边界全部由 P8/P6C/P6D 保存预测装配（F1 的 Qp 行取 P8 B1，其余目标取 P6C/P6D 对应行），不新拟合内层模型。主指标 = qp × PF EG0 × area_low 伪边界单元；约束 = P6D balanced 分数。判据同 P7/P8：主指标改善 ≥20% 且约束恶化 ≤5% → 选 F1，否则保留 F0。协议特别要求逐单元报告 area_edges 拟合集 area_low=900 的 fl0/fl1 单元（P8 中 B1 在该单元恶化 0.033→0.356），确认该恶化在仅 Qp 子模型中依旧存在并记录其量级。

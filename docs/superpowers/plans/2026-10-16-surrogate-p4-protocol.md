# P4 受限寻优协议

日期：2026-10-16。在阅读 P3 测试及边界结果之后制定；所有后续分析是回顾性审查，不是新盲测。

## 审查结论与本轮决策

P3 的结构典型值区间不等于单器件范围、四目标联合区间或寻优后冠军的保证。冻结测试中的四目标同时覆盖设计组比例为 23/34；面积边界 k² 覆盖 62/96；FL 上边界 BodeQ_fitted 覆盖 40/72。几何凸包与逐维已知水平只是支持描述，不代表统计可信度。

本轮不重训、不选超参数、不重新分割、不扩大区间迎合已见测试。继续使用冻结 ExtraTrees，仅用于探索性搜索。暂缓 GP、贝叶斯优化、NSGA-II；有限候选网格可直接穷举，不需要随机搜索来代替可核验答案。复杂模型的合理下一步须有预先冻结的新验证与独立数据。

## P4 契约

- 主数据直接读 P3 `data/structures.csv`；只接受标准拓扑、去嵌结构典型值，不重新整理工作簿。原始 ZIP、Excel、数据库、旧 HTML 和所有 P3 产物保持只读。
- `measured` 模式枚举既有结构；四目标均有至少 10 个有效坐标才进入完整向量排名。四项单目标 Top-N 和 Pareto 均使用同一行的四项目标，保留来源 mark、结构 ID、bootstrap 区间、位置波动。描述为“既有实测目录内的最优”，不是已验证新尺寸或唯一统计冠军。
- `exploratory` 模式由显式网格枚举、分批调用 P3 模型。输入网格只是计算网格，不推断制造步长或特殊拓扑含义。不接受 AG、raw/de 混合、其他 Bode 口径。保留逐目标 P3 区间及其含义，但不以区间下界冒充稳健最优。
- 附加局部支持：在同一拟合分支上，每维使用相邻训练水平；只有所需单元全部角点都在该目标训练集时，标记 `complete_local_cell`。精确训练点单列；缺角点、越界、未知分支被拒绝参与探索排名。该规则是保守的几何启发式，不是经校准的准入证明，全部代理结果继续 `trusted_for_unmeasured_optimization=false`。
- 可信标志不能由用户配置打开。实测与代理结果分目录；代理即使恰好命中已测坐标，也不混入观测值形成拼接向量。
- 支持显式几何范围、四项目标下限、离散 PF 与 Top-N。频率窗口只用于实测目录的 `fs_ghz/fp_ghz` 典型值；探索模式没有频率模型，遇到频率约束明确拒绝。典型值满足约束不代表所有器件满足，也不代表联合物理谱已验证。
- 不自动生成权重或综合冠军。所有目标最大化；Pareto 为有限可行候选集合的非支配集，严格支配要求至少一项更好。相等向量保留，单目标同分按结构 ID 确定顺序，不称唯一冠军。
- 未知字段、非法尺寸、非有限数、缺目标、超规模网格报错；无可行点导出明确空结果与逐条拒绝原因，不放宽约束。输出目录存在即拒绝覆盖。

## 复现与验收

新增源码仅在指定 ML worktree；独立输出 `backend/surrogate_data/optimization_p4_20261016/`。记录 P3 输入哈希、配置、源码、版本、候选数、耗时及全部输出哈希。先校验 P3 清单，再运行只读分组覆盖审查。

测试覆盖完整/缺角局部单元、退化维度、跨分支、非法输入、约束、空结果、Pareto 与独立朴素枚举一致、四目标值来自同一行。实际执行默认实测、带约束实测、不可行实测、显式探索网格，以及 CLI 覆盖保护。验证 P3 清单、原 dirty 文件前后不变。不把功能检查当成预测验证。

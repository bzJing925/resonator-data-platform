# P5 离线结果页面实施边界

承接用户“继续”，交付受限 P4 的离线使用界面，不重训或开放可信外推。

- 在指定 ML worktree 新增独立 TypeScript 页面和 Python 构建器，生成单文件 HTML；沿用本地 uv 和现有 TypeScript/Playwright，不增加依赖，不改旧代理模型 HTML。
- 构建前核对 P4 交付清单，读取完整 `candidates.csv`，区分实测与探索，不用仅含 Top-N 的 `results.json` 冒充完整候选目录。
- 默认打开实测目录。支持四目标切换、目标下限、几何范围、PF、实测频率范围；对当前可行集合重算四目标 Pareto 与排序。探索仍遵守 P4 `eligible`，不能通过页面开关绕过局部支持规则。
- 页面明确“筛选已计算目录”；不提供新尺寸在线预测，不推断制造步长、AG 或特殊拓扑。频率约束在探索模式不可用，切换模式清空过滤条件和比较选择。
- 图、表、详情、比较和导出共享同一状态及结构 ID。最多比较四个结构，展示完整四目标向量、区间口径、有效坐标或逐目标支持状态。
- 提供完整筛选集 CSV/JSON、Pareto CSV、排除记录 CSV；导出保留原始精度和来源信息，不用界面四舍五入后的数值计算。另可导入构建器生成的浏览数据包，导入后显示来源声明未独立校验。
- 不接受未知格式、异常值、重复 ID、错误模式、被改成可信标志的数据包；插入文本转义，导出 CSV 防止文本被解释为公式。任何导入失败保持原状态。
- 文件输出与证据在新的 P5 目录；构建与测试不得覆盖 P3/P4。交付可双击使用的 HTML、浏览数据包、构建/验收清单及使用说明。

验收：file:// + 浏览器离线模式启动；四目标 Top-N/Pareto 与 P4 对照；正/反约束、无解、非法范围、模式切换、点表联动、比较、导出数值、重新导入、拒绝无效数据、窄屏与桌面截图。保留浏览器错误/外部请求检查和 P3/P4 前后哈希证据。P5 功能验收不等于新尺寸预测或物理验证；M2 仍需独立实测。
